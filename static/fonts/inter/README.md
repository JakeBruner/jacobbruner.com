# Original website font

These Inter variable font assets and CSS are preserved from @fontsource/inter 4.5.15,
the version used on the original prod branch. Keeping the original font preserves
text metrics and wrapping during the framework upgrade. They are static font data,
not an installed JavaScript dependency. The accompanying SIL Open Font License applies.
